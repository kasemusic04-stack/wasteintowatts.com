# Waste → Watts: Smart siting for waste-to-energy hubs in Guwahati

An interactive web app that finds the best places in Guwahati to turn waste into energy. It scores every 30 m of the city on eight factors (water, floods, waste, roads, homes, forest reserve, power grid, open land) using AHP, removes off-limits land, and picks five hub sites that cut daily truck driving by about 53% compared with the Boragaon dump.

**Live site:** https://kasemusic04-stack.github.io/wasteintowatts.com/

## What's inside
- `index.html`: the whole app in one file (maps, data and code included). It loads D3.js from cdnjs.

## Built with
ArcGIS Pro, Python (rasterio, GeoPandas, SciPy), AHP weighted overlay, D3.js.
